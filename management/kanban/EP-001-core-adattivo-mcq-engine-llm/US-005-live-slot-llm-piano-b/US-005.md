# US-005 — Live slot LLM e Piano B (DEMO_MODE, fallback, test offline)

## Descrizione

Come presentatore in demo, voglio poter selezionare un distractor non presente nelle fixtures e ottenere una spiegazione generata dal LLM in tempo reale, e voglio che il prodotto funzioni ugualmente a rete staccata, affinché la capability agentica sia dimostrabile live senza rischio di crash.

Stima: P-A incluso in slot 0:15–1:25 (logica explainer.js). Test offline: slot 3:30–4:00. Dry run finale: 4:30–4:45.

## Business Rules

- Il live slot si attiva SOLO per distractor non trovati in fixtures.json. DEMO_MODE è ON per default: il live slot chiama la rete SOLO quando DEMO_MODE=false.
- L'output LLM usa schema JSON strict con i campi `headline`, `spiegazione`, `analogia`. L'output grezzo NON va mai al DOM: passa OBBLIGATORIAMENTE per renderRemediation() con filtro denylist.
- Tier 3 (fallback): se il live slot restituisce errore o supera il timeout, la UI mostra il fallback testuale pre-scritto entro 3 secondi. Nessuno spinner infinito. Il presentatore usa la frase: "Vi mostro il prompt che questa chiamata avrebbe eseguito."
- A 3:45h il team stacca fisicamente la rete ed esegue il flusso completo. Se qualcosa crasha si risolve prima della demo — non dopo.
- La chiave API del provider LLM non compare in nessun file sorgente e non viene inviata al browser in chiaro.

## Acceptance Criteria

- [ ] Selezionando un distractor non in fixtures.json con DEMO_MODE=false, la UI mostra una spiegazione generata dal LLM qualitativamente diversa da quelle in fixtures — verificabile dalla giuria confrontando output su due distractor diversi dello stesso step.
- [ ] Con rete staccata (offline test a 3:45h), il flusso completo L1 sbaglia → remediation → riprova → avanza completa senza errori di rete visibili all'utente.
- [ ] `grep -c renderRemediation *.js` = 1 (unico entry point, copre fixtures e live slot).
- [ ] La chiave API non è presente in nessun file sorgente del progetto (grep su tutti i file *.js, *.html, *.json per il valore letterale della key).
- [ ] Se il live slot restituisce errore HTTP o timeout, la UI mostra il fallback testuale pre-scritto entro 3 secondi senza crash e senza spinner bloccato.

# TSK-004 — quiz-engine.js: pdpLevel gate + carico curriculum L1/L2

## Context

Parte di US-002 (Engine MCQ). Il gate clinico centrale del prodotto: il percorso studente non può avviare senza che il docente abbia configurato `pdpLevel`. Nessun valore di default, nessun fallback silenzioso. Single-writer invariant: solo la form docente (TSK-013) scrive `pdpLevel` — questo TSK aggiunge il commento esplicito nel codice e il gate di avvio.

[^src: management/kanban/EP-001-core-adattivo-mcq-engine-llm/US-002-engine-mcq-state-machine/US-002.md §Business Rules]

## Technical Specs

- **FE:** aggiunta a `engine.js` — funzione `startSession()` che legge `pdpLevel` da `localStorage.getItem('pdpLevel')`, ritorna errore se null/undefined
- **Gate:** `if (!pdpLevel) throw new Error('pdpLevel non configurato. Vai alla view docente.')` — fail-loud, non silenzioso
- **Single-writer comment:** nel blocco di `localStorage.setItem('pdpLevel', ...)` della form docente (TSK-013), aggiungere commento `// SINGLE-WRITER: solo questa funzione assegna pdpLevel. Non aggiungere altri writer. [gate clinico]`
- **Branch L1 vs L2:** la funzione `loadCurriculum(pdpLevel)` (da TSK-003) usa `pdpLevel` per selezionare il subset di step corretto. La policy scaffold-fading (L1: number line visibile dal primo errore; L2: solo dopo 2 tentativi) è leggibile da `data/pdp-levels.json`
- **pdp-levels.json:** creare `data/pdp-levels.json` con campi `{level_id, max_denominator, show_number_line_after_errors}` (L1: 1, L2: 2)

## Implementation Steps

1. In `engine.js`, aggiungere `startSession()`: legge `pdpLevel` da localStorage, lancia eccezione se non presente.
2. Creare `data/pdp-levels.json` con entry L1 e L2 (max_denominator, show_number_line_after_errors).
3. In `loadCurriculum()`, leggere anche `data/pdp-levels.json` e salvare le policy sull'istanza engine.
4. Aggiungere getter `engine.getScaffoldPolicy()` → ritorna `show_number_line_after_errors` per il livello corrente.
5. Aggiungere nel codice, vicino alla gestione localStorage, il commento `// NO cross-tab sync by design. Role round-trip via URL param reload. [ADR Round 2 PA-R2-1]`.
6. Testare: avviare senza pdpLevel in localStorage → deve lanciare l'eccezione. Impostare pdpLevel='L1' → deve partire.

## Definition of Done

- [ ] `startSession()` lancia errore se `localStorage.getItem('pdpLevel')` è null (test manuale in console)
- [ ] `data/pdp-levels.json` esiste con entry L1 e L2 con campi `max_denominator` e `show_number_line_after_errors`
- [ ] `grep -c pdpLevel engine.js` mostra 0 occorrenze di scrittura (solo lettura in engine.js)
- [ ] Il commento `// NO cross-tab sync by design` è presente vicino alla gestione localStorage
- [ ] `engine.getScaffoldPolicy()` ritorna `{show_number_line_after_errors: 1}` per L1 e `2` per L2

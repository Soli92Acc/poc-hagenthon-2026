# US-009 — Scheda genitore plain-language (bonus condizionale al checkpoint)

## Descrizione

Come genitore di Luca, voglio vedere un riepilogo in linguaggio comune di cosa ha fatto Luca nella sessione, senza terminologia clinica, affinché possa seguire il percorso di mio figlio senza interpretare report tecnici.

Stima: P-B 15 min (lookup table JSON + render schermata ?role=parent). Slot: buffer 3:30–4:00, SOLO se il buffer non è stato consumato da bug critici. Se il buffer è consumato, questa storia non si implementa.

## Business Rules

- ATTIVATA SOLO se al checkpoint 2:30h il team è in GO con buffer tecnico intatto. Se checkpoint è PARZIALE o il buffer è stato consumato, questa storia non si implementa e `?role=parent` mostra una schermata "Funzionalità in arrivo" senza crash.
- Implementazione: una funzione toParentLanguage() con lookup table in un file JSON separato che mappa misconcepto_slug → frase in linguaggio comune. Esempio: `denominator_magnitude` → "Luca sta imparando a confrontare le frazioni guardando le dimensioni, non i numeri".
- La schermata genitore è read-only: nessuna form, nessun bottone di azione, nessuna opzione di configurazione.
- Zero terminologia clinica, zero diagnosi implicita, zero raccomandazioni riabilitative nella schermata.
- La lookup table è in un file JSON separato (non inline nel codice applicativo) per rispettare l'invariante di scalabilità EP-2.

## Acceptance Criteria

- [ ] (Condizionale — solo se implementata) Navigando a `?role=parent`, l'interfaccia mostra frasi in linguaggio comune senza termini della clinical-denylist — verifica grep su DOM renderizzato.
- [ ] (Condizionale) Il mapping `denominator_magnitude` → frase incoraggiante esiste nel file JSON lookup e produce output leggibile da un genitore non specialista.
- [ ] (Condizionale) La schermata genitore è read-only: inspect DOM non mostra elementi `<form>`, `<input>` o `<button>` attivi.
- [ ] Se non implementata: `?role=parent` mostra una schermata statica "Funzionalità in arrivo" o redirect a studente — senza errori JavaScript né crash visibili.
- [ ] In nessun caso il genitore può vedere dati di sessione studente non redatti: il solo output sono le frasi in linguaggio comune della lookup table.

# TSK-022 — Script narrativo demo 3 min + accordo speaker/clicker

## Context

Parte di US-012 (Script narrativo demo). Primo task del blocco demo prep 4:00-4:45. Lo script deve esistere su supporto fisico (carta o file condiviso) prima del rehearsal. Deve assegnare esplicitamente chi parla e chi clicca per ogni fase. Durata target ≤3 min.

[^src: management/kanban/EP-004-demo-e-deliverable/US-012-script-narrativo-demo/US-012.md §AC]

## Technical Specs

- **Supporto:** carta stampata o Google Docs condiviso — qualcosa che entrambi possono leggere durante la demo senza dover dividere lo schermo
- **Struttura script (5 fasi obbligatorie):**
  1. Docente configura L1 (chi parla: ?, chi clicca: ?)
  2. Luca sbaglia step 2 → misconcepto denominator_magnitude (chi parla: ?, chi clicca: ?)
  3. Remediation + number line + riprova + avanzamento (chi parla: ?, chi clicca: ?)
  4. Transfer task "Prova questa!" senza number line → risposta autonoma (chi parla: ?, chi clicca: ?)
  5. Live probe: distractor non in fixtures → LLM live → output diverso (chi parla: ?, chi clicca: ?)
- **Risposte giuria (≥2 preparate):**
  - "Cos'è la capability agentica?" → risposta preparata (targeting misconcepto specifico, non risposta generica)
  - "Come si scala a nuovi contenuti?" → risposta preparata (Extension Point EP-1: aggiungere JSON, zero JS)
  - "Come gestite il confine clinico?" → risposta preparata (denylist deterministico + unico entry point)
- **Regola durata:** leggere lo script ad alta voce prima del rehearsal — se supera 4 min, accorciare il testo (non velocizzare il parlato)

## Implementation Steps

1. Scrivere le 5 fasi con battute brevi e dirette (max 2-3 frasi per fase in narrativa).
2. Per ogni fase: annotare [PARLA: P-A/P-B] e [CLICCA: P-A/P-B].
3. Scrivere le 3 risposte-giuria (2-3 frasi ciascuna).
4. Leggere ad alta voce e cronometrare. Se >4 min → accorciare.
5. Entrambi devono avere una copia o accesso al documento.

## Definition of Done

- [ ] Lo script è scritto su supporto condiviso (non solo in testa a uno dei due)
- [ ] Le 5 fasi obbligatorie sono coperte nell'ordine corretto
- [ ] Ogni fase ha speaker/clicker esplicitato
- [ ] Almeno 2 risposte-giuria scritte (non improvvisate)
- [ ] Lettura ad alta voce ≤4 min (cronometro durante la redazione)

## Dependencies

- Nessuna dipendenza tecnica (lo script può essere abbozzato in qualsiasi momento della giornata, ma viene finalizzato nel blocco 4:00-4:15)

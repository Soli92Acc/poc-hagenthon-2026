# TSK-012 — URL param router (?role=) + lettura pdpLevel localStorage

## Context

Parte di US-006 (Configurazione PDP docente). P-A implementa la logica di routing in `app.js`: il URL param `?role=teacher|student|parent` determina quale funzione di render viene chiamata sull'AppState condiviso. Questo è il meccanismo che permette le tre audience senza cross-tab sync.

[^src: management/kanban/EP-002-viste-per-ruolo/US-006-configurazione-pdp-docente/US-006.md §Business Rules]

## Technical Specs

- **FE:** `app.js` — funzione `initRouter()` chiamata all'avvio
- **Logica routing:** `new URLSearchParams(window.location.search).get('role')` → `'teacher' | 'student' | 'parent' | null`; default se null: `'student'`
- **Render dispatch:** switch/case → chiama `renderTeacherView()` / `renderStudentView()` / `renderParentView()`
- **pdpLevel:** `renderStudentView()` legge `localStorage.getItem('pdpLevel')` → se null → mostra schermata "Configura il livello con il docente prima di iniziare" (non lancia eccezione nel browser)
- **Commento obbligatorio:** nel blocco localStorage, aggiungere `// NO cross-tab sync by design. Role round-trip via URL param + reload. [PA-R2-1]`
- **Nessun listener `storage`:** verificare con grep che non esistano listener `addEventListener('storage', ...)` nel codice

## Implementation Steps

1. In `app.js`, scrivere `initRouter()`: legge URL param, chiama la funzione di render corretta.
2. Implementare `renderStudentView()` (stub): legge pdpLevel, se null mostra messaggio "Vai alla view docente per configurare il livello", altrimenti chiama `engine.startSession()`.
3. Implementare `renderTeacherView()` (stub iniziale: solo il placeholder, sarà completata in TSK-013).
4. Implementare `renderParentView()` (stub: mostra "Funzionalità in arrivo" — conforme US-009 condizionale).
5. Aggiungere il commento `// NO cross-tab sync by design` nel blocco localStorage.
6. Chiamare `initRouter()` in DOMContentLoaded.
7. Verificare: navigare a `?role=teacher` → vede placeholder docente; `?role=student` senza pdpLevel → vede messaggio configurazione; `?role=student` con `localStorage.setItem('pdpLevel','L1')` → parte la sessione.

## Definition of Done

- [ ] `?role=teacher` mostra view docente placeholder
- [ ] `?role=student` senza pdpLevel in localStorage mostra messaggio di configurazione (non crash)
- [ ] `?role=student` con pdpLevel='L1' in localStorage avvia `engine.startSession()`
- [ ] `grep -c "addEventListener.*storage" app.js engine.js explainer.js` = 0 (nessun listener storage)
- [ ] Il commento `// NO cross-tab sync by design` è presente nel codice

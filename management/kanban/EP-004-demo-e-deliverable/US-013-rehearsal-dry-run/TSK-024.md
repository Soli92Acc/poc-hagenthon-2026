# TSK-024 — Dry run offline: rete fisicamente staccata, flusso completo pre-demo

## Context

Parte di US-013 (Dry run offline). Slot 4:30-4:45. NON NEGOZIABILE: il dry run non viene sacrificato per nessuna altra attività incluso il PPT. Questo è distinto dal test offline di sviluppo (TSK-011): qui si tratta della simulazione finale della demo in condizioni identiche alla presentazione, inclusa la rete staccata. Se qualcosa crasha qui, si risolve qui.

[^src: management/kanban/EP-004-demo-e-deliverable/US-013-rehearsal-dry-run/US-013.md §Business Rules]

## Technical Specs

- **Setup:** WiFi fisicamente disabilitato (o adattatore staccato). Browser NON ricaricato — la app è già in memoria con fixtures in cache.
- **Flusso completo:** fasi 1-5 dello script completo + simulazione risposta-giuria su almeno 1 domanda
- **Piano B demo live slot:** con rete staccata, la fase 5 (live probe) non può chiamare OpenRouter. Il presentatore deve avere pronta la frase: "Vi mostro il prompt che questa chiamata avrebbe eseguito" + aprire il file prompt.txt sul desktop. Questo è il Tier 3 della demo.
- **Fix critici:** se qualcosa crasha durante il dry run → identificare, fixare (rete ripristinata), ri-eseguire il flusso rotto. La demo non parte finché il dry run non è PASS.
- **Dichiarazione:** al termine del dry run PASS, entrambi dichiarano verbalmente "demo pronta".

## Implementation Steps

1. Disabilitare WiFi fisicamente.
2. Eseguire il flusso completo seguendo lo script: fasi 1-5 con ruoli assegnati.
3. Verificare che la fase 5 (live slot con rete staccata) degrada gracefully al Tier 3 senza crash.
4. Simulare una domanda della giuria con la risposta preparata.
5. Annotare eventuali crash o comportamenti inattesi.
6. Se crash: riconnettere rete, fixare, re-eseguire dall'inizio.
7. Se PASS: dichiarare "demo pronta" verbalmente.
8. Ripristinare WiFi.

## Definition of Done

- [ ] Il flusso completo (fasi 1-5) eseguito con rete staccata senza crash o errori JavaScript visibili
- [ ] La degradazione Tier 3 del live slot funziona senza spinner bloccato (rete off + chiave non in fixtures)
- [ ] Almeno 1 risposta-giuria rehearsed
- [ ] Entrambi i partecipanti dichiarano "demo pronta"
- [ ] Eventuali fix applicati e dry run re-eseguito prima della dichiarazione finale

## Dependencies

# TSK-007 — Plain language review curriculum (D6 gate)

## Context

Parte di US-003 (Content JSON discalculia). Questo task NON è delegabile al LLM né a P-A. P-B legge ogni testo del curriculum e verifica tre cose: (1) frasi ≤15 parole, (2) zero termini della clinical-denylist, (3) valori position_pct geometricamente corretti. Il review manuale è il gate D6 (entro 1:25h).

[^src: management/kanban/EP-001-core-adattivo-mcq-engine-llm/US-003-content-json-discalculia/US-003.md §Business Rules]

## Technical Specs

- **Input:** `data/curriculum-discalculia.json` scritto in TSK-006
- **Verifica 1 — lunghezza frasi:** contare le parole di ogni frase di ogni testo. Max 15 parole per frase. Spezzare le frasi che la violano.
- **Verifica 2 — denylist:** eseguire `grep -rn` dei termini della denylist su `data/*.json`. I termini chiave: diagnosi, disturbo, deficit, riabilit, clinic, specialista, dislessia, DSA, certificaz, valutazione (come radici). Zero match tollerati nei file JSON del curriculum.
- **Verifica 3 — position_pct:** controllare che 1/3 (≈0.333) sia a destra di 1/4 (0.25) nella number line, che 1/5 (0.2) sia a destra di 1/6 (≈0.167). Visualizzare mentalmente: position_pct più alto = più a destra = frazione più grande. Se i valori sono invertiti = misconcepto visivo (esattamente quello che vogliamo evitare).
- **Verifica 4 — linguaggio Luca (11 anni, 1a media):** leggere ogni testo ad alta voce. Evitare frasi subordinate complesse, parole desuete, termini che richiedono conoscenza scolastica superiore alla 1a media.

## Implementation Steps

1. Aprire `data/curriculum-discalculia.json`.
2. Per ogni campo testuale (label di distractor, domande, eventuali hint): contare le parole di ogni frase. Segnare le violazioni.
3. Eseguire: `grep -rni 'diagnosi\|disturbo\|deficit\|riabilit\|clinic\|specialist\|disless\|certificaz\|valutaz' data/*.json` → deve restituire 0 risultati.
4. Verificare i valori position_pct: 1/3>1/4, 1/5>1/6, 1/7<1/5 (tutti corretti per la number line).
5. Correggere i problemi trovati direttamente nel JSON.
6. Dichiarare D6 completato verbalmente a P-A.

## Definition of Done

- [ ] Ogni frase di ogni testo nel curriculum JSON ha ≤15 parole (conteggio manuale, P-B firma il check)
- [ ] `grep -rni 'diagnosi\|disturbo\|deficit\|riabilit\|clinic\|specialist' data/*.json` → 0 risultati
- [ ] I valori `position_pct` sono geometricamente corretti (1/3≈0.333 > 1/4=0.25, 1/5=0.2 > 1/6≈0.167)
- [ ] P-B ha letto ogni testo ad alta voce e lo ha giudicato comprensibile per uno studente di 11 anni
- [ ] D6 dichiarata completa a P-A (verbalmente o su chat di progetto)

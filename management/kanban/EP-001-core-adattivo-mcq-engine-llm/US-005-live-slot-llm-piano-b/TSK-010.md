# TSK-010 — E2E test flussi L1/L2 + live slot test + grep gate confine clinico (D4)

## Context

Parte di US-005 (Live slot LLM e Piano B). Questo è il test di integrazione completo che verifica D4 (flusso E2E entro 2:25). Testa i due flussi nominali (L1 errore→remediation, L2 nominale), il live slot con 1-2 req reali, e i gate meccanici del confine clinico. La verifica deve essere completata entro il checkpoint GO/NO-GO 2:25-2:30.

## Technical Specs

- **Budget OpenRouter per questo TSK:** max 2 req (1 per test live slot DEMO_MODE=false, 1 di riserva per retry). Aggiornare il contatore fisico.
- **Test 1 — Flusso L1 errore:** seleziona L1 in form docente → step1 → clicca il distractor `denominator_magnitude` → verifica che `#feedback-region` mostri headline e spiegazione dalla fixtures.json entro 2s, senza chiamate di rete (DevTools Network tab: zero req durante rendering)
- **Test 2 — Flusso L2 nominale:** seleziona L2 → step1 → risposta corretta → verifica avanzamento a step2 senza remediation
- **Test 3 — Live slot:** impostare `DEMO_MODE=false` nel console del browser, selezionare un distractor non presente in fixtures.json → verifica che il proxy risponda e `#feedback-region` mostri testo LLM (non fallback). Rimettere `DEMO_MODE=true` subito dopo.
- **Grep gate confine clinico (US-011):** eseguire `grep -c renderRemediation explainer.js app.js engine.js` → valore totale = 1. Eseguire `grep -c "pdpLevel" engine.js | grep -v read` → 0 writer trovati in engine.js.
- **Gate scalabilità:** `grep -nE 'misconcepto|frazione|denominatore' *.js` → 0 risultati.

## Implementation Steps

1. Aprire browser + DevTools (tab Network aperta).
2. Navigare a `http://localhost:8080`, impostare L1 in form docente.
3. Eseguire flusso L1: step1 → distractor errato (denominator_magnitude) → verifica feedback da fixtures (zero req in DevTools Network).
4. Eseguire flusso L2: impostare L2 → step1 → risposta corretta → verifica avanzamento.
5. Live slot test: aprire console, `DEMO_MODE=false`; step1 → distractor NON in fixtures → verifica risposta LLM (1 req in DevTools Network). Rimettere `DEMO_MODE=true`.
6. Eseguire grep gate: `grep -c renderRemediation *.js` = 1. `grep -nE 'misconcepto|frazione|denominatore' *.js` = 0.
7. Segnare esito: GO / PARZIALE-A / PARZIALE-B / NO-GO.

## Definition of Done

- [ ] Flusso L1 errore completo: feedback da fixtures in ≤2s, DevTools Network 0 req durante remediation
- [ ] Flusso L2 nominale: avanzamento senza remediation
- [ ] Live slot test passato: risposta LLM qualitativamente diversa da fixtures (1-2 req contati)
- [ ] `grep -c renderRemediation *.js` = 1
- [ ] `grep -nE 'misconcepto|frazione|denominatore' *.js` = 0
- [ ] Contatore req OpenRouter aggiornato: totale ≤17 su 50 disponibili
- [ ] Esito checkpoint documentato (GO/PARZIALE/NO-GO) su carta o chat

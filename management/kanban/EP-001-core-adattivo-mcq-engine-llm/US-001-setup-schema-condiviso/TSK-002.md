# TSK-002 — index.html + Tailwind CDN + HTML semantico + footer permanente

## Context

Parte di US-001 (Setup e schema condiviso). P-B prepara la shell HTML in parallelo con TSK-001. Questo file è la base su cui tutti i componenti FE successivi vengono costruiti. Il footer permanente (requisito US-011 confine clinico) va qui sin dall'inizio per essere presente su tutte le view.

[^src: management/kanban/EP-001-core-adattivo-mcq-engine-llm/US-001-setup-schema-condiviso/US-001.md §AC]

## Technical Specs

- **FE:** `index.html` single-file, Tailwind CDN (`<script src="https://cdn.tailwindcss.com">`), zero npm/build
- **Font e palette:** `font-size: 18px` sans-serif (Tailwind: `text-[18px] font-sans`), colori `#1a1a1a` su `#ffffff`, soddisfano contrasto AA 4.5:1
- **Landmark HTML5:** `<header>`, `<main>`, `<nav>` (tab-role), `<footer>` — struttura semantica corretta per screen reader
- **Footer permanente (US-011 gate):** testo esatto `"NumeriMiei è uno strumento didattico compensativo per studenti con diagnosi certificata di discalculia ai sensi della Legge 170/2010. Non sostituisce la valutazione clinica o il percorso previsto dal PDP."` — visibile in viewport senza scroll su tutte le view
- **Include:** `<script src="app.js">` e `<script src="engine.js">` e `<script src="explainer.js">` (file vuoti per ora, P-A li riempirà)

## Implementation Steps

1. Creare `index.html` con DOCTYPE + lang="it" + charset=UTF-8.
2. Aggiungere `<script src="https://cdn.tailwindcss.com">` in `<head>`.
3. Impostare `<body class="bg-white text-[#1a1a1a] text-[18px] font-sans min-h-screen flex flex-col">`.
4. Struttura: `<header>` con titolo "NumeriMiei", `<main id="app">` (placeholder vuoto), `<footer>` con testo Legge 170/2010.
5. Aggiungere placeholder `<div id="view-student">`, `<div id="view-teacher">`, `<div id="view-parent">` in main (nascosti, P-A li gestirà via router).
6. Aggiungere `<script src="app.js" defer>`, `<script src="engine.js" defer>`, `<script src="explainer.js" defer>`.
7. Creare file vuoti: `app.js`, `engine.js`, `explainer.js`.
8. Aprire nel browser e verificare che il footer sia visibile senza scroll.

## Definition of Done

- [ ] `index.html` caricabile con `python3 -m http.server 8080` senza errori in console
- [ ] Footer con testo Legge 170/2010 visibile in viewport senza scroll
- [ ] Font 18px sans-serif e palette #1a1a1a/#ffffff verificate in DevTools
- [ ] Struttura landmark HTML5 corretta (inspect DOM: header, main, footer presenti)
- [ ] File `app.js`, `engine.js`, `explainer.js` esistono (anche vuoti)
- [ ] Tailwind CDN caricato e le classi di utilità funzionano

# US-002 — Engine MCQ con state machine e misconcepto targeting

## Descrizione

Come studente, voglio rispondere a esercizi MCQ su confronto di frazioni e ricevere un feedback che nomina il mio errore specifico, affinché io possa capire quale meccanismo ho sbagliato — non solo che "ho sbagliato".

Stima: P-A 60 min, P-B 25 min. Slot: 0:15–1:25.

## Business Rules

- La state machine percorre gli stati: STEP → REMEDIATION → NEXT → COMPLETION. Lo stato PROFILING è sostituito dalla configurazione docente (US-006): il percorso studente non parte senza pdpLevel impostato.
- Per ogni opzione errata nella MCQ, il curriculum JSON associa un `misconcepto_slug` — non una risposta generica a tutti gli errori.
- Il sistema carica gli esercizi in base al `pdpLevel` impostato dalla view docente. Nessun default: senza pdpLevel configurato, il percorso non avvia.
- Dopo 3 tentativi consecutivi falliti sullo stesso step, la UI mostra il messaggio di stop fisso e termina il percorso per quello step — nessuna ulteriore remediation.
- Nessun contenuto del misconcepto (nomi di errori, testi di frazioni specifiche) è inline nella logica applicativa: viene letto dai file dati a runtime.
- Gate scalabilità: `grep -nE 'misconcepto|frazione|denominatore' *.js` deve restituire 0 risultati al checkpoint 2:25.

## Acceptance Criteria

- [ ] Selezionando l'opzione errata che corrisponde a `denominator_magnitude` nello step 1 con L1, la UI mostra entro 2 secondi un feedback con la headline del misconcepto corrispondente — non un testo generico "Risposta errata".
- [ ] Selezionando un distractor diverso sullo stesso step, la UI mostra una headline di misconcepto diversa — la spiegazione è qualitativamente diversa.
- [ ] Dopo 3 tentativi consecutivi falliti sullo stesso step, la UI mostra il messaggio di stop ("Questo esercizio è meglio affrontarlo con il tuo insegnante") e non mostra pulsante Riprova.
- [ ] Cambiando `pdpLevel` da L1 a L2 nella view docente, il set di esercizi caricato cambia (L1: denominatori ≤4; L2: denominatori ≤10) — verificabile confrontando le due view in demo.
- [ ] `grep -nE 'misconcepto|frazione|denominatore' *.js` restituisce 0 risultati al checkpoint 2:25.

# TSK-019 — A11y set A: tabular-nums + no-animation + prefers-reduced-motion + contrasto + feedback non solo colore

## Context

Parte di US-010 (Must-have a11y discalculia). P-B applica il primo gruppo di requisiti a11y specifici per discalculia: quelli che si implementano con CSS puro su elementi già esistenti (tabular-nums, animazioni, contrasto, icone feedback). Non richiedono nuovi componenti. Gate D5: tutti i must completati entro 2:25.

[^src: management/kanban/EP-003-accessibilita-confine-clinico/US-010-must-have-a11y-discalculia/US-010.md §AC]

## Technical Specs

- **font-variant-numeric: tabular-nums:** su TUTTI gli elementi che contengono cifre (frazioni, denominatori, contatori). Tailwind: `font-numeric` o inline `style="font-variant-numeric: tabular-nums"` (Tailwind CDN supporta `[font-variant-numeric:tabular-nums]`).
- **No-animation su numeri:** dichiarare `transition: none` e `animation: none` su tutti gli elementi numerici. Per default, Tailwind non aggiunge transizioni — verificare che nessuna classe Tailwind le aggiunga per errore.
- **prefers-reduced-motion:** aggiungere in `<style>` o inline: `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }`. Testare con DevTools (emulazione prefers-reduced-motion: reduce).
- **Contrasto AA 4.5:1:** verificare #1a1a1a su #ffffff con DevTools contrast ratio checker (già soddisfatto dalla palette di TSK-002, ma verificare con DevTools).
- **Feedback non solo colore (WCAG 1.4.1):** aggiungere icona o shape al feedback corretto (es. ✓ verde) e al feedback errato (es. ✗ rosso). L'icona deve essere visibile anche con simulazione deuteranopia in DevTools (Rendering → Emulate vision deficiency).
- **HTML semantico + focus outline 3px:** verificare che tutti gli elementi interattivi abbiano focus outline visibile (Tailwind: `focus:outline focus:outline-3 focus:outline-offset-2`).

## Implementation Steps

1. Aggiungere `font-variant-numeric: tabular-nums` a tutte le classi CSS degli elementi numerici (o come stile globale su elementi con cifre).
2. Aggiungere media query `prefers-reduced-motion` nel `<style>` di index.html.
3. Verificare contrasto: DevTools → Inspector → elemento testo → sezione Accessibility → Contrast ratio ≥4.5:1.
4. Modificare il render di feedback: aggiungere `<span aria-hidden="true">✓</span>` per corretto e `<span aria-hidden="true">✗</span>` per errato oltre al colore.
5. Verificare con simulazione deuteranopia (DevTools → Rendering → Emulate vision deficiency: Deuteranopia) che il feedback sia distinguibile senza affidarsi solo al colore.
6. Verificare focus outline: navigare con Tab → ogni pulsante ha outline visibile.

## Definition of Done

- [ ] DevTools computed styles: `font-variant-numeric: tabular-nums` presente su elementi con cifre
- [ ] DevTools animation tab: zero animazioni attive su elementi numerici in stato normale
- [ ] `prefers-reduced-motion: reduce` (emulazione DevTools) rimuove tutte le transizioni UI
- [ ] DevTools contrast ratio: #1a1a1a su #ffffff ≥4.5:1 (verified)
- [ ] Feedback corretto/errato ha icona/shape aggiuntiva visibile anche con simulazione deuteranopia
- [ ] Focus outline 3px visibile su tutti gli elementi interattivi (Tab navigation)

# TSK-013 — Form PDP docente: select L1/L2/L3 + button + copy obbligatorio

## Context

Parte di US-006 (Configurazione PDP docente). P-B costruisce la UI della view docente: il form di selezione del livello PDP. Questa view è il gate clinico: senza di essa il sistema dovrebbe assegnare il livello autonomamente (vietato). Il copy dell'interfaccia è prescritto e non modificabile.

[^src: management/kanban/EP-002-viste-per-ruolo/US-006-configurazione-pdp-docente/US-006.md §AC]

## Technical Specs

- **FE:** sezione `<div id="view-teacher">` in `index.html` + funzione `renderTeacherView()` completata in `app.js`
- **Label obbligatoria:** `"Seleziona il livello indicato nel PDP del tuo studente."` — verbatim, non modificare
- **Select:** `<select id="pdp-level-select">` con opzioni L1, L2, L3 (no opzione "seleziona..." come default — forza scelta esplicita)
- **Button confirm:** `<button id="btn-confirm-pdp">Conferma e inizia sessione</button>` — disabilitato se nessun valore selezionato
- **Handler confirm:** scrive `localStorage.setItem('pdpLevel', selectedValue)` → questa è l'unica occorrenza di scrittura di pdpLevel nel codice; aggiungere commento `// SINGLE-WRITER: solo questa funzione scrive pdpLevel [gate clinico]`
- **Post-confirm:** redirect a `?role=student` con `window.location.href = '?role=student'`
- **Report link:** nella view docente, dopo una sessione completata, mostrare un link "Vedi report sessione" → `?role=teacher#report`

## Implementation Steps

1. In `index.html`, nella sezione `<div id="view-teacher">`: aggiungere `<p>` con il copy obbligatorio, `<select>` con opzioni L1/L2/L3 (value: "L1", "L2", "L3"), `<button id="btn-confirm-pdp" disabled>`.
2. In `app.js`, completare `renderTeacherView()`: show `#view-teacher`, nasconde altre view.
3. Aggiungere listener on `change` su select: abilita il button.
4. Aggiungere listener on `click` su button: `localStorage.setItem('pdpLevel', select.value)` + commento SINGLE-WRITER + redirect a `?role=student`.
5. Aggiungere sezione report (placeholder): `<div id="teacher-report-section" hidden>` — sarà popolata da TSK-017.
6. Testare: navigare a `?role=teacher` → select visibile + copy obbligatorio → selezionare L1 → conferma → redirect a `?role=student` → `localStorage.getItem('pdpLevel')` = 'L1'.

## Definition of Done

- [ ] `?role=teacher` mostra il copy esatto "Seleziona il livello indicato nel PDP del tuo studente."
- [ ] La select ha 3 opzioni (L1, L2, L3) e nessuna opzione pre-selezionata
- [ ] Il pulsante è disabilitato finché nessun valore è selezionato
- [ ] Dopo conferma L1: `localStorage.getItem('pdpLevel')` = 'L1' (verifica console)
- [ ] Il commento `// SINGLE-WRITER` è presente sull'unica riga `localStorage.setItem('pdpLevel', ...)` nel codice
- [ ] `grep -c "setItem.*pdpLevel" app.js engine.js explainer.js index.html` = 1 (unico writer)

- TSK-012 — il router deve esistere per fare redirect a `?role=student` dopo conferma

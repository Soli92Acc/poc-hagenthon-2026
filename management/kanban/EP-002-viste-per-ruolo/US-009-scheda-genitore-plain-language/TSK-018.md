## Technical Specs

- **Condizione di attivazione:** checkpoint 2:30h = GO + buffer intatto
- **File:** `data/parent-language.json` (lookup table slug → frase incoraggiante) + `renderParentView()` in `app.js`
- **Lookup table:** `{"denominator_magnitude": "Luca sta imparando a confrontare le frazioni guardando le dimensioni, non i numeri", "numerator_focus": "Luca sta esplorando come il numero in cima alle frazioni ci aiuta a capire le quantità"}` — zero terminologia clinica, zero diagnosi implicita
- **toParentLanguage(misconcepto_slug):** lookup in `parent-language.json`, ritorna frase incoraggiante
- **Vista genitore:** schermata read-only, mostra solo le frasi della lookup table (non dati grezzi di sessione), zero form/input/button. Zero termini denylist clinica.
- **Fallback se non implementata:** `renderParentView()` mostra `<p>Funzionalità in arrivo</p>` — già implementato come stub in TSK-012. Nessuna modifica necessaria se il task non viene eseguito.

## Implementation Steps

1. Verificare al checkpoint 2:30h: GO con buffer intatto? Se NO → skip questo task.
2. Creare `data/parent-language.json` con mapping slug → frase incoraggiante (2-3 entry minimo).
3. In `app.js`, implementare `toParentLanguage(slug)`: carica `parent-language.json` → lookup → ritorna frase.
4. Completare `renderParentView()`: legge `session_errors` da localStorage, per ogni slug unico chiama `toParentLanguage(slug)`, mostra lista di frasi.
5. Verificare: inspect DOM — zero `<form>`, `<input>`, `<button>`. Zero termini denylist clinica nel testo.
6. Navigare `?role=parent` → verificare che mostra le frasi in linguaggio comune.

## Definition of Done

- [ ] `data/parent-language.json` esiste con ≥2 mapping slug → frase incoraggiante
- [ ] La frase per `denominator_magnitude` è comprensibile da un genitore non specialista (test: leggi ad alta voce)
- [ ] Inspect DOM `?role=parent`: zero `<form>`, `<input>`, `<button>` attivi
- [ ] Nessun termine della clinical-denylist nel testo renderizzato (`grep` o verifica manuale)
- [ ] Se task non eseguito: `?role=parent` mostra "Funzionalità in arrivo" senza crash JavaScript
